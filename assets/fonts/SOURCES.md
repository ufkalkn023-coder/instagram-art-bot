# Editorial cover fonts

The cover renderer uses the unmodified static OpenType fonts below. Paths resolve
from the repository, so local rendering and Actions do not depend on OS fonts.

- Source Serif 4 Regular: [Adobe Source Serif](https://github.com/adobe-fonts/source-serif/tree/80d3f8894c09c937bebfa9011247d2e1c79fd6f4),
  `OTF/SourceSerif4-Regular.otf`, release commit
  `80d3f8894c09c937bebfa9011247d2e1c79fd6f4`.
- Source Sans 3 Regular: [Adobe Source Sans](https://github.com/adobe-fonts/source-sans/tree/87b37a2daaed80fcb8e8ccb0085c4d72ddade12e),
  `OTF/SourceSans3-Regular.otf`, release commit
  `87b37a2daaed80fcb8e8ccb0085c4d72ddade12e`.

Each font's SIL Open Font License is included in its directory. The older font
assets remain in place for their existing callers; the new cover uses only the
two Adobe files above.
